# Project Guide (AGENTS.md)

## Code Rules
- Never add extra code, extra lines, or unused words.
- Never add extra styling, extra libraries, or decorative features.
- Every line, import, and word in the code must be used. Remove anything unused.
- Keep the code minimal, readable, and modular. No AI-style comments or polished filler.
- Follow existing patterns in the repo. One module = one job.
- Contracts between modules are frozen. Never rename/remove fields; only add optional ones if needed.

Customer Feedback Insight System (Cognizant hackathon).
